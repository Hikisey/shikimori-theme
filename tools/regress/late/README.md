# Инструменты разноса `overrides/late.css` (v1.7.4–v1.7.9)

Пути внутри скриптов указывают на рабочую машину (`/workspace/st`, `/workspace/rf`, `/workspace/pw`); при запуске в другом месте поправьте их или задайте `SRC=<путь к src>`.

- `snap.js`, `gen_urls.py` — корпус страниц: живая страница с JS сайта сохраняется как HTML без скриптов и без `#custom_css`, тема подставляется вместо `<!--THEME-->`.
- `cascade.py` — разбор CSS, специфичность, пересечение свойств (сокращения, логические), совместимость субъектов, пересечение медиазапросов, взаимоисключающие страницы (классы `body`), классы, ни разу не встречающиеся на одном элементе (`clsidx.py` → `clsidx.pkl`).
- `plan.py`, `pairs.py` — для каждого блока `late.css`: модуль-хозяин и конфликтующие правила между концом модуля и `late.css`.
- `comatch.js` — для пар конфликтующих селекторов: совпадают ли они хоть на одном элементе корпуса.
- `move.py map.tsv [--evidence comatch.json] [--apply]` — проверка и перенос блоков (строка в `late.css` → модуль); переносит в конец модуля с тем же медиазапросом, порядок переносимых между собой сохраняется.
- `closure.py` — наибольший набор блоков, который можно перенести вместе.
- `remap.py` — пересчёт номеров строк карты после изменений `late.css`.
- `selsmap.py` + `affected.js` — страницы корпуса, на которых переносимые селекторы что-то находят (на остальных перенос ничего не меняет).
- `cdiff2.js A.css B.css out fixtures...` — сверка вычисленных стилей: ПК 1920/1280, планшет 1024, телефон 390, принудительные `:hover`/`:focus`/`:focus-visible`/`:active`/`:focus-within`, `prefers-reduced-motion`, переходы/анимации, `::before`/`::after`/`::placeholder`/`::marker`. `RESUME=1` продолжает прерванный прогон, `SKIPP` — свойства, которые не сравнивать. `d_report.py` отбрасывает известный шум.
