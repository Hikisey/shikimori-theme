# Обои

- `bg.webp`, `bg_m.webp` — обои по умолчанию (алый вариант темы).
- `bg_blue.webp`, `bg_blue_m.webp` — обои для примера с синим акцентом в README.

Синие обои сделаны из фотографии [Kanchenjunga South Peak](https://commons.wikimedia.org/wiki/File:Kanchenjunga_South_Peak_%28Unsplash%29.jpg) (Mukesh Jain, Unsplash, [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)): обрезаны под 2560×1440 (ПК) и 900×1440 (телефон) и сохранены в WebP.
